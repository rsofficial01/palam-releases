# Palam

Palam is SolAi on your computer. Hold a key, ask out loud in any language, and let go. Palam looks at your screen,
answers out loud and points at what it means. It does something for you only after you say "yes".

## Install on a Mac

1. Open **Palam-Mac.zip** and drag **Palam** into your **Applications** folder.
2. Double-click Palam. macOS says it can't check Palam for malicious software, because our Apple signing is still
   being approved. Click **Done**.
3. Open **System Settings › Privacy & Security**, scroll to "Palam was blocked…", click **Open Anyway**, type your
   Mac's password, and click **Open Anyway** again. You do this once.
4. Allow the Microphone, Accessibility and Screen Recording when Palam asks.
5. Hold **Control + Option** and ask.

## Install on Windows

1. Right-click **Palam-Windows.zip** › **Extract All…** into a folder you keep (for example `C:\Users\<you>\Palam`).
2. Double-click **Palam.exe**. If Windows says "Windows protected your PC", click **More info › Run anyway** (our code
   signing is still being set up).
3. Hold **Ctrl + Alt + Space** and ask.

## Good to know

- Escape, or saying "stop", ends an answer midway.
- Palam takes a picture of your screen only when you ask it something. It never clicks or types on banking or payment
  pages, or into password boxes.
- Palam tells you when a new version is out.
